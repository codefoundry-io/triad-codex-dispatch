## Candidate behavior

- Run TRIAD from the same authenticated login terminal and project worktree
  used for development. Provider, user, and project settings own permission and
  workspace-trust selection. TRIAD does not install or override a permission
  mode, profile, rule, pre-spawn environment policy, or trust bypass.
- Trusted terminal, Python, and `PATH` startup are prerequisites. Wrapper
  child-process scrubbing remains after trusted launcher/interpreter startup;
  it is not a permission controller.
- Native AGY `permission-unavailable` is a distinct terminal post-dispatch
  result and cannot activate Gemini fallback in the same round. Gemini owns its
  native workspace-trust decision; TRIAD has no `--skip-trust` replacement.
- Bootstrap installs the three provider wrapper launchers through the existing
  staged all-or-nothing publication transaction. It pins the install-resolved
  classifier path and prints the direct login-shell
  `python3 bin/apply_patch.py` owner argv with the same required explicit
  `--classifier-file`.
- Repair analysis uses a fresh native proposal-only child with
  prompt-controlled no-edit behavior. No repair Custom Agent or apply launcher
  is installed.

## Full-coverage formal review

The full diff is navigation evidence bound to the complete affected-source
closure, exact current source bytes, candidate state, and deterministic receipt
contract. The leader prepares one immutable prepared directory and records one
simple content digest plus the source-tree and change-evidence digests.

Every required family reviews every affected production source in every
deterministic batch. For this candidate the exact no-exclusion boundary includes
all repository test source. Each path requires a source-grounded observation,
exact full-file range, changed-hunk or impact-edge evidence, and a strict receipt.
Strict admission rejects missing batches, families, paths, observations,
digests, or unresolved questions.

Provider-native file-read telemetry is retained and digest-bound when exposed.
When it is not exposed, coverage is prompt-controlled and admitted through
source-grounded receipts, independent family review, and leader reproduction;
TRIAD does not claim provider-enforced proof of every read.

Current source must be UTF-8. A non-UTF-8 source fails closed with
`non-UTF-8 source`; it cannot be omitted from the closure. Defer the candidate
or obtain owner approval for a separately reviewed design that adds support.

The operational pre-merge profile is `batched-full-coverage`. The unbatched
`formal-gate` and packaged `FormalReview` result remain compatibility surfaces
only; they cannot substitute for the strict `BatchReceipt` matrix.

## Google fallback migration

Ordinary/non-formal Gemini fallback is limited to a no-final-summary exit `4`
(`EXIT_BINARY_MISSING`) plus the wrapper-owned pre-submission `PtyStartError`
diagnostic for a supported missing or unstartable executable. Every
final-summary result is fallback-ineligible.

Missing or invalid `TRIAD_AGY_BIN` and missing `agy` on `PATH` are direct,
fallback-ineligible route-setup errors rather than fallback triggers. Install or
configure AGY, or explicitly authorize a separate Google route.

Formal Gemini use requires separate owner authorization for the exact route,
provider, data boundary, and objective. It keeps the same immutable prepared
directory, prompt-controlled no-edit/no-execution contract, digest/mutation
invalidation, full batch matrix, and strict admission. An unavailable required
family leaves an invalid round.

## Upgrade and cleanup

- Remove retired wrapper `--sandbox` flags from callers; permission selection
  now belongs to native provider/user/project configuration.
- Exact plugin-owned legacy profiles, command rules, repair-agent registration,
  pre-spawn `[shell_environment_policy]` fragments, agent TOMLs, and retired
  launchers are removed only when markers and expected bytes match.
- Foreign, edited, linked, unreadable, or non-regular targets are preserved and
  reported. Owner-authored settings, rules, permission profiles, credentials,
  and unrelated files are preserved.
